# 软件工程

> 软件开发的生命周期：
>
> 需求 -> 原型图 -> UI 设计 -> 开发 -> 测试 -> 部署 -> 运维

## **软件工程应用内容**

1. 编程语言与开发工具
   - 各种编程语言（JavaScript、Python 等）及相关 IDE、调试工具。
2. 软件设计与架构
   - 面向对象设计、微服务架构、设计模式。
3. 数据库
   - 关系型与非关系型数据库的设计与优化。
4. CI/CD 和 DevOps
   - 持续集成与部署工具（如 Jenkins、Docker、Kubernetes）。
5. 项目管理
   - 敏捷开发、Scrum、版本控制（Git）。
6. 测试与质量保证
   - 单元测试、集成测试、性能测试。
