## View full configuration 查看完整的配置 ✨✨✨

要将完全扩展的 CI/CD 配置作为一个组合文件查看，请转到流水线编辑器的 **完整配置** 选项卡。此选项卡显示扩展配置，其中：

- 使用 `include` 导入的配置被复制到视图中。
- 使用 `extends` 的作业，扩展配置合并显示到作业。
- YAML **锚点**由链接配置替代。
- YAML `!reference` 标签也被链接配置替换。
